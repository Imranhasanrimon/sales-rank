# SalesRank.Ai

This project is a pixel-perfect AI-powered web application landing page built based on the provided Figma design. It demonstrates responsive UI development, clean architecture, and a functional chat box using React and Tailwind CSS.

## Tools/packages used

- HTML
- CSS
- Tailwind CSS
- DaisyUI
- JavaScript
- React.js


## Installation

Install SalesRank.Ai project with npm

```bash
  git clone https://github.com/Imranhasanrimon/sales-rank.git
  cd sales-rank
  npm install
```
Live Link: https://sales-rank-task.netlify.app/
